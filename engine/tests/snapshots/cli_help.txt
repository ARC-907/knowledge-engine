### knowledge-engine --help
usage: knowledge-engine [-h] [-v | -q]
                        {info,bootstrap,capabilities,reindex,watch,registry,config,mcp,search,embeddings,knowledge,serve,project-context,board,board-serve} ...

positional arguments:
  {info,bootstrap,capabilities,reindex,watch,registry,config,mcp,search,embeddings,knowledge,serve,project-context,board,board-serve}
    info                Print configuration and counts
    bootstrap           Walk corpus/ and register every folder as an entry
    capabilities        Print runtime capability and retrieval-surface
                        inventory
    reindex             Rebuild FTS5 index over enabled entries
    watch               Start watchdog: auto-register new corpus folders
    registry            Inspect the corpus registry (registry.json)
    config              Inspect the effective configuration
    mcp                 Run the MCP server for AI clients (stdio, or
                        streamable HTTP with --http)
    search              Search the index
    embeddings          Corpus embedding index for vector / hybrid search
                        (build, search, status)
    knowledge           Scoped-knowledge metadata: migrate the corpus, status,
                        workspaces, projects, collections, classification
    serve               Run the FastAPI server (uvicorn)
    project-context     Project-specific documentation subsystem
    board               Agent Board (post/read/search/ack/sweep/keys)
    board-serve         Run the standalone Agent Board service (separate
                        port).

options:
  -h, --help            show this help message and exit
  -v, --verbose         More log output on stderr (-v: INFO, -vv: DEBUG).
  -q, --quiet           Less log output on stderr (-q: ERROR, -qq: CRITICAL).

### knowledge-engine embeddings build --help
usage: knowledge-engine embeddings build [-h] [--incremental | --rebuild]
                                         [--provider {fake,ollama,remote}]
                                         [--model MODEL] [--db DB]
                                         [--batch BATCH]
                                         [--chunk-size CHUNK_SIZE]
                                         [--chunk-overlap CHUNK_OVERLAP]
                                         [--max-chars MAX_CHARS]

options:
  -h, --help            show this help message and exit
  --incremental         only embed new or changed files
  --rebuild             drop the index first (required to switch to another
                        model)
  --provider {fake,ollama,remote}
                        embedding provider (default: $KE_EMBED_PROVIDER or
                        ollama; fake: offline dry run)
  --model MODEL         embedding model (default: $KE_EMBED_MODEL or bge-m3)
  --db DB               index database (default: $KE_EMBEDDINGS_DB or
                        <data_dir>/embeddings.db)
  --batch BATCH         chunks per embedding request (default: $KE_EMBED_BATCH
                        or 32)
  --chunk-size CHUNK_SIZE
                        characters per chunk (1500)
  --chunk-overlap CHUNK_OVERLAP
                        characters of overlap between chunks (200)
  --max-chars MAX_CHARS
                        characters of each chunk sent to the model (2000)
